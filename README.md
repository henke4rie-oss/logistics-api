# Logistics API

A containerized backend service built with Python, FastAPI, and PostgreSQL for managing cargo shipments, bulk manifest processing, and operational reporting.

## Tech Stack
* **Language:** Python 3.11+
* **Framework:** FastAPI
* **Database:** PostgreSQL (SQLAlchemy ORM)
* **Testing:** Pytest
* **Containerization:** Docker

## Features
* CRUD management for logistics cargo shipments.
* Automated bulk manifest payload validation and processing.
* Isolated integration testing suite (5/5 passing).
